> **非官方第三方工具。** EVE Online 及相关商标、标识与游戏内素材的全部权利归
> **Fenris Creations（原 CCP Games，2026-05 更名）** 所有。本工具与其无隶属、赞助或背书关系，

EVE Online 单机桌面工具套件 —— 把「市场行情（对标 ISK.GG）/ 资产估值（对标 jEveAssets）/ 工业计算（对标 Fuzzworks）」三类能力整合进一个**本地应用**：
**零服务器、零账号体系、数据全部留在你自己的机器上**。

## 这是什么

**三大基座**（对标成熟工具，但全部本地化）：

| 基座 | 对标 | 你能做什么 |
|---|---|---|
| 市场行情 | ISK.GG | 查物品价格、看 400 天历史走势、盯监视列表、导出 CSV |
| 资产管理 | jEveAssets | 授权后看全账号资产、钱包、订单、合同、工业任务、采矿账簿、LP；每日净值快照 |
| 计算器 | Fuzzworks | 蓝图成本、LP 比价、矿石精炼值 —— 与官网已知算例对照 |

**六个整合功能**（这些是单点工具做不到的）：

| 功能 | 一句话 |
|---|---|
| **库存缺口分析** | 蓝图 BOM × 你全账号的库存 → 缺什么、买多少、去哪个枢纽买、总共多少钱 |
| **LP 优化器** | 每军团 offer 的 ISK/LP 排名 × 你的实际 LP 余额 → 换什么最划算 |
| **精确净值** | 统一估值口径（默认卖价 5% 分位，抗 1 ISK 钓鱼单）× 全部资产，基准可切区域 / 站点 |
| **工业成本闭环** | 工业任务关联钱包流水：安装费「预算 vs 实际」偏差 + 产出毛利 |
| **采矿时薪** | 矿石精炼值 × 采矿账簿 → 按 EVE 日 / 月聚合的每小时 ISK 收益 |
| **Undercut 提醒** | 你的卖单被压价超过阈值 → 系统通知 + 钉钉 / 企业微信 / 飞书群 |

**外加**：70 个区域的跨区价差扫描（找搬砖机会）。

## 下载与安装

到 **[Releases](https://github.com/q956720465/eve-suite/releases)** 页面下载对应平台的安装包。

| 平台 | 产物 | 安装方式 |
|---|---|---|

| **macOS** | `.dmg` | 打开后把 App 拖进「应用程序」 |
| **Linux** | `.AppImage` / `.deb` / `.rpm` | AppImage 需 `chmod +x` 后直接运行 |

### 安装前的两点预期

本工具**未做代码签名**（证书需自费），因此首次安装会看到系统警告，属正常现象：

- **Windows**：若出现"Windows 已保护你的电脑" → 点「**更多信息**」→「**仍要运行**」。
- **macOS**：若提示"来自身份不明的开发者" → 在「应用程序」里**右键（或 Control+点击）该 App → 打开** → 再点「打开」。

### 运行环境

- **Windows 10 及以上**（需要系统自带的 WebView2 运行时，Win11 默认已装）
- 无需安装 .NET、Python 或数据库 —— 所有依赖都打进安装包

## 首次使用（约 10 分钟）

### 第 1 步：导入静态数据（约 1 分钟）

打开应用 → 顶部「**数据**」页 → 点右上角「**下载并导入**」。

应用会从官方拉取 SDE（约 95MB），本地解压入库。完成后状态显示
`就绪 · SDE <版本号> · 53060 个物品`，此时物品搜索可用。

> 这一步只需做一次；以后官方更新 SDE 时点「**检查更新**」即可增量重导。

### 第 2 步：连接你的 EVE 账号（约 2 分钟）

顶部「**资产**」页 → 点「**授权新角色**」。

会在系统浏览器打开 **EVE 官方登录页**（`login.eveonline.com`）—— 用的是官方 OAuth，
应用内**不会**、也**无法**接触你的账号密码。登录后点「授权」，浏览器会提示"可以关闭此页面"。

回到应用，角色卡出现即授权成功。

> 刷新令牌存在**操作系统钥匙串**（Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service），
> 不落数据库、不上传任何服务器。

### 第 3 步：等待首次同步（约 1 分钟）

授权后应用会**自动开始同步**，把七类个人数据拉到本地：

资产 · 钱包（余额 + 账本）· 市场订单 · 合同 · 工业任务 · 采矿账簿 · 忠诚点（LP）

也可以随时点「**立即同步**」手动触发（默认每 20 分钟自动同步一轮，并遵守官方缓存有效期）。

### 第 4 步：看净值

同步完成后，「**资产**」页上方即为**全账号合计净值**（资产 + 钱包 + 卖单 + 合同），
下方是分角色明细，可切换估值基准（区域 / 站点 / 价格口径）。

到这里核心链路就通了。行情数据会在后台自动采集（5 大枢纽每 5 分钟一轮），无需手动操作。

## 功能一览（按页签）

| 页签 | 能做什么 |
|---|---|
| **数据** | SDE 下载 / 更新；物品与空间站**中英文搜索**；物品详情（体积、质量、基础价、描述） |
| **行情** | 枢纽行情浏览、400 天价格图；**全域层**跨区快照（档位 3 / 6 / 12 / 24 小时 / 关闭，覆盖 65 个非枢纽区） |
| **价差** | 跨区价差排行（两段式过滤：订单簿粗筛 + 30 天历史校验，自动剔除钓鱼单与孤岛价）；**历史数据全量初始化**（400 天，手动触发，约 3.6 万对品种） |
| **监视** | 监视列表（物品 + 区域）与 6 小时聚合历史、CSV 导出 |
| **资产** | 角色授权与同步、全账号净值、资产明细、订单 / 合同 / 工业 / 采矿 / LP 分项、每日净值快照 |
| **计算** | 7 个子页签：**蓝图成本** · **库存缺口** · **LP 比价** · **矿石精炼值** · **采矿时薪** · **工业对账** · **算例对照** |
| **提醒** | Webhook 通道配置（钉钉加签 / 企业微信 / 飞书 / 自定义）+ 测试发送；Undercut 规则；监视列表价格带；静默时段；立即检查 |
| **关于** | 版本、**软件更新（自动检查 / 一键更新）**、数据存放位置、数据来源、许可与合规 |

### 计算页的 7 个子页签

| 子页签 | 输入 | 输出 |
|---|---|---|
| 蓝图成本 | 蓝图 + 流程数 + ME/TE | 材料清单、总成本、单件成本、任务时长 |
| 库存缺口 | 蓝图 + 流程数 + ME | 缺口清单、采购总价、建议购买枢纽、理论下限 |
| LP 比价 | 军团（自动带你的 LP 余额） | 每个 offer 的 ISK/LP 与总价值排行 |
| 矿石精炼值 | 矿石 + 数量 + 产出率 + 税 | 精炼产物、净产值、每单位 / 每 m³ 产值 |
| 采矿时薪 | 采矿速率（m³/小时）+ 矿石 | 每小时 ISK 收益；下方是**采矿账簿复盘**（按 EVE 日 / 月 / 矿石 / 星系聚合） |
| 工业对账 | 材料效率假设（ME） | 逐任务「安装费预算 vs 实际」偏差 + **产出毛利**；下方是监视价格带规则 |
| 算例对照 | 无 | 与第三方公开算例逐项比对（静态量判零误差，价格类只展示漂移） |

## 常见问题（FAQ）

**Q：Windows 提示"Windows 已保护你的电脑"，是病毒吗？**
不是。本工具**未购买代码签名证书**，SmartScreen 对未签名的应用一律警告。点「更多信息」→「仍要运行」即可。
介意的话可以自行核对源码（全部开源）或从源码构建。

**Q：macOS 双击打不开？**
未签名 + 未公证的应用会被 Gatekeeper 拦截。按住 **Control 键点击 App → 打开 → 再点「打开」**；之后就能正常双击了。

**Q：我的数据存在哪？怎么备份 / 迁移？**
单个 SQLite 文件（应用内「关于」页有各平台完整路径）：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\com.eve-suite.desktop\eve-suite.db` |
| macOS | `~/Library/Application Support/com.eve-suite.desktop/eve-suite.db` |
| Linux | `~/.config/com.eve-suite.desktop/eve-suite.db` |

复制这个文件即可备份；关掉应用后替换它即可迁移。**卸载应用不会自动删除它**。

**Q：我的账号安全吗？令牌会被上传吗？**
不会有任何上传。应用**没有服务端**：OAuth 走官方 PKCE 流程，刷新令牌存进**系统钥匙串**；
其余数据全部写在上面那个本地文件里。仓库源码可查，无遥测、无统计上报。

**Q：怎么撤销授权 / 彻底删除某个角色的数据？**
在「资产」页选中该角色 → 点「**登出并清除本地数据**」。这会删除本地保存的刷新令牌
（钥匙串条目）与该角色的全部个人数据（资产 / 钱包 / 合同 / 工业 / 采矿等）。
若还想在官方侧撤销应用授权，到 EVE 账号管理的第三方应用页面移除即可。

**Q：必须一直开着应用吗？**
提醒功能（Undercut / 价格带）**只在应用运行时**生效 —— 这是单机工具的固有属性（没有服务端帮你盯着）。
行情采集与个人数据同步同理。关掉应用后重新打开，会自动补跑过期的轮次。

**Q：断网了还能用吗？**
可以。价格图、资产、工业对账、库存缺口、采矿时薪、精炼值、蓝图成本、LP 比价等**全部是本地计算**，
读的都是本地已缓存的数据。只有这几件事需要联网：下载 / 更新 SDE、同步个人数据、采集新行情，
以及「价差」页对候选做**历史校验**（断网时该步会被跳过并在行内标注）。

> 想离线也保留「价差」的完整判定，可在联网时用「历史数据全量初始化」把 400 天历史一次拉全。

**Q：为什么有物品显示"缺报价"？**
该物品在你所选基准（区域 / 站点）的本地订单簿里没有有效卖单。常见原因：
① 该枢纽确实无人挂单 ② 该枢纽还没采集到数据（在「行情」页点「**立即采集**」，或确认没有处于「已暂停」状态）
③ 选了站点级基准而该站点无货。
缺价按 0 计入估值，会让总价偏低 —— 所以界面上会**具名列出**，不会静默吞掉。

**Q：用这个会被封号吗？**
不会。本工具只做两件事：读**官方公开**的行情 / SDE 接口，以及在你**本人授权**后读你自己的角色数据
（官方 OAuth + 官方 ESI scope），并严格遵守官方要求的缓存头，不重复拉取、不伪造请求。
**不读写游戏内存、不注入游戏进程、不自动操作游戏**。

**Q：占多少磁盘？**
安装包约 **15MB**。数据库随使用增长：导入 SDE 与基础行情后约百 MB 量级；
若执行「历史数据全量初始化」（400 天 × 约 3.6 万品种），会涨到 **1.3GB** 量级。
该功能是**可选**的 —— 只影响「价差」历史校验的覆盖面与价格图的回看长度，跳过不影响其它功能。

**Q：怎么更新到新版本？**
应用**启动 10 秒后会自动检查一次**（也可以随时在「关于」页点「**检查更新**」）。
发现新版本时会显示版本号与发行说明，点「**立即更新**」下载安装，完成后自动重启。
更新只在**你本机到 GitHub 之间直连**，没有中间服务器；更新包在发布时用**私钥签名**，
应用内用内置公钥校验 —— **签名不符会被拒绝安装**。

## 数据与隐私

- **零服务器**：项目不含任何后端服务，也没有开发者服务器；数据不会离开你的机器。
- **无账号体系**：没有"注册登录"，只有你自己对官方 OAuth 的授权。
- **无遥测**：不收集使用统计、崩溃上报或任何行为数据。
- **令牌**：OAuth 刷新令牌存于操作系统钥匙串，**不落数据库**。
- **Webhook**（可选）：只有你主动配置钉钉 / 企业微信 / 飞书机器人地址后，
  命中提醒时才会向你指定的地址 POST 消息；地址与加签密钥存在本机 `settings` 表。
- **无公司资产**：目前只同步你个人角色的数据，不读取公司（corp）资产与钱包。

## 开发者：技术栈与构建

> 应用内「关于」页与 [DEV_STATUS.md](./DEV_STATUS.md)（进度与下一步）是了解实现现状最快的入口。
> 完整设计见开发方案：[EVE 工具套件 · 单机桌面版完整开发方案.md](<./EVE 工具套件 · 单机桌面版完整开发方案.md>)。

### 技术栈

| 层 | 选型 |
|---|---|
| 桌面壳 | Tauri 2（Rust） |
| 核心逻辑 | 纯 TypeScript 包 `@eve-suite/core`（不依赖任何 UI） |
| 界面 | React 19 + Vite 8 |
| 数据库 | SQLite（WAL 模式，Rust 侧自管 sqlx 连接池） |
| 包管理 | pnpm workspace monorepo |
| 测试 | Vitest（core 包可离线运行） |
| 分发 | GitHub Actions 三平台构建 → GitHub Releases |

### 目录结构

```

├── packages/
│   ├── core/            # 纯 TS 核心包：数据库 / SDE / ESI / 四大引擎 / 六大整合功能 / 提醒
│   │   ├── src/db/      # DbAdapter 契约（含事务原语）+ 迁移执行器 + 迁移清单 + 运行时适配器
│   │   ├── src/sde/     # SDE 解析 / 导入 / 搜索 + 运行时数据源
│   │   ├── src/market/  # 行情采集 / 统计 / 全域层 / 价差 / 按需历史 / 监视列表
│   │   ├── src/personal/# 个人数据同步（七类）+ 净值
│   │   ├── src/engines/ # 估值 / 蓝图 / LP / 精炼 / 库存缺口 / 采矿 / 工业对账
│   │   ├── src/notify/  # 提醒规则引擎 + Webhook 通道（含钉钉加签）
│   │   └── test/        # vitest 测试（node:sqlite 适配器 + 连接池模拟适配器）
│   └── ui/              # React 界面层（Vite，dev 端口固定 1420）
├── src-tauri/           # Tauri 2 壳（Rust）：窗口 / 自有命令 / 打包配置
│   ├── src/db.rs        # 自管 sqlx 连接池 + 事务会话命令
│   ├── src/sde.rs       # SDE 下载 / 解压 / 分块读取
│   ├── src/notify.rs    # 系统通知 + Webhook POST（必须在主进程发，渲染进程受 CORS 限制）

```

### 环境要求

- **Node ≥ 24**（core 测试依赖内建 `node:sqlite`；本机 v25.2.1 已验证）
- **pnpm 11.7.0**（根 `package.json` 的 `packageManager` 字段已锁定版本）
- **Rust ≥ 1.85**（由 sqlx 0.8 / reqwest 0.13 决定；本机 1.98.1 已验证）
- Windows 10+ 自带 WebView2 运行时

```bash

# 离线测试（core 包，无需 Tauri 运行时）

# 启动桌面应用（Tauri 窗口 + Vite 热更新）
```

### 版本号约定

**唯一真源是 `src-tauri/tauri.conf.json` 的 `version`**（打包实际使用的版本）。

```bash
pnpm version:sync     # 同步到根/各包 package.json 与 Cargo.toml
pnpm version:check    # 只校验一致性（不一致退出码 1，供 CI 使用）
```

**不要手工修改其余位置的版本号**；`packages/core` 的 `CORE_VERSION` 直接读取本包 `package.json`，
源码内不存在版本字面量。

### 国内镜像

| 文件 | 作用 |
|---|---|
| `.npmrc` | npm 依赖统一走 `registry.npmmirror.com` |
| `.cargo/config.toml` | crates 依赖走 `rsproxy.cn`（sparse 协议） |

**约定**：CI（GitHub Actions，境外机器）在构建前会移除这两个文件、直连官方源 —— 该逻辑已写入 workflow，请勿修改。

### CI / CD（GitHub Actions）

workflow 文件：`.github/workflows/build.yml`

| 触发 | 行为 |
|---|---|
| push 到 `main` | 三平台（windows-latest / macos-latest / ubuntu-22.04）并行构建，产物上传到该次运行的 Artifacts |
| push `v*` tag | 等三平台构建全部完成后，把全部安装包自动发布到 GitHub Release |

### 数据库约定

- 单文件 SQLite（WAL 模式）；连接层在 Rust 侧自管 sqlx 连接池（WAL / 外键 / `busy_timeout` 由连接选项统一设置）
- 迁移机制：`packages/core/src/db/migrations/` 按版本号累积执行，版本记录于 `schema_migrations` 表
- **规则**：
  - 已发布的迁移文件禁止修改，只能新增新版本文件
  - 多条语句的迁移必须使用 `statements` 数组（驱动 `execute` 只执行第一条语句）
  - core 内禁止裸写 `BEGIN` / `COMMIT`，一律走 `DbAdapter.transaction(fn)`（连接池下裸写会跨连接失效）

### SDE 静态数据

- 应用内「下载并导入」一键完成：从 EVE Online 官方拉取 SDE（约 95MB zip）→ 解压缓存到 `sde-cache/` → 批量入库
- 实测：build 3542233 共 12 万行入库，耗时约 **11 秒**
- 名称取 SDE 自带的 8 语言（落库 en / zh 两列），支持中英文搜索
- 空间站名由「星系 + 行星序号 + 拥有者军团 + 作业名」本地合成（SDE 不含站名）
